# 此刻的一页 · 答案之书

纯静态网站，打开 index.html 即可体验（推荐现代浏览器）。

- 固定识别码由商品卖家单独提供；同一标签页会话内免重复输入。
- 365条原创答案，等概率随机抽取，心情标签仅为仪式感，不影响抽取。
- 3D CSS 连续翻页，合书回到封面；可关闭合成翻页声。
- 保存书页生成 1080×1440 PNG，不含操作按钮。
- 无外部依赖、无需后端、不收集问题或心情。
- 固定码仅是前端访问门槛，熟悉代码的人可绕过；不是严格的付费鉴权。

## GitHub Pages 部署
1. 创建公开仓库，上传 index.html 和 .nojekyll 到仓库根目录。
2. Settings → Pages → Deploy from a branch → main / (root) → Save。
3. 部署完成后即可访问 GitHub Pages 地址。自定义域名在 Pages 中填写，并在域名服务商设置 CNAME 指向 GitHub Pages 用户域名，待证书签发后启用 Enforce HTTPS。

注意：不要在公开仓库文档或商品宣传中公布识别码。
